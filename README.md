# RAPAX / Hyperion — V6 High-Fidelity Website Prototype

## Open locally

1. Extract the ZIP.
2. Open `RAPAX-Hyperion-V6/site/index.html` in any modern browser.
3. Navigate using homepage links, shop product cards, product pages, the shared header/footer, or the **All Pages** footer link.
4. Open `all-pages.html` directly to review the complete page inventory.

No build step or server is required for the static prototype. Internet connectivity may improve Encode Sans loading; images and logos are bundled locally. Ethnocentric is referenced but **not embedded** because it was not supplied as a licensed webfont.

## Project scope

- V4/V5 homepage is preserved, with only the requested THE LINEUP text contrast correction.
- The other site pages are fully redesigned in V6 and linked together.
- Shop filters, product gallery thumbnails, FAQ accordions and mobile navigation are interactive.
- Product prices, active shopping-cart operations and checkout are not present.
- `cart.html` is a **design-only, empty cart state**; it is not connected to a store.
- `contact.html` submission reports demo-only status and does not send data.
- Polymer Compact is listed, but final model data and photography need client approval.
- Policy pages are drafts for client legal review.

See `V6-DESIGN-NOTES.md` for content sources, page listing, open decisions, and `QA-REPORT.md` for test results.
